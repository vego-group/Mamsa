# عقد لوحة الشريك — الشكاوى

**التاريخ:** 06/09/2026
**المستودع:** `vego-group/mamsa-partner-dashboard`
**البيئة:** `https://staging.mamsaa.com` — **جذر، بدون `/api/v1`** · كوكي جلسة، حارس `dashboard`
**الحالة:** المسارات حيّة على staging

> **قراءة فقط.** الشريك مش بيتصرف في الشكوى — بيشوفها وبيشوف أثرها على رصيده. مفيش أي endpoint كتابة في العقد ده، وده مقصود: الشكوى نزاع بين طرفين وممسى بتتوسط فيه.

---

## 1. المسارات

```
GET /me/complaints        → { items: PartnerComplaintRow[] }
GET /me/complaints/{id}   → PartnerComplaintDetail
```

الترميز **camelCase** زي باقي لوحة الشريك.

### القائمة

```ts
type PartnerComplaintRow = {
  id: number
  status: 'submitted' | 'under_review' | 'approved' | 'resolved_refunded' | 'resolved_rejected'
  bookingCode: string | null
  unitName: string | null
  createdAt: string | null      // ISO-8601 Zulu
}
```

الرد: `{ "items": [...] }` — مفيش pagination على المسار ده حالياً؛ الشكاوى لكل شريك قليلة.

### التفاصيل

```ts
type PartnerComplaintDetail = {
  id: number
  status: PartnerComplaintRow['status']
  description: string                     // نص الضيف كما هو
  bookingCode: string | null
  unitName: string | null
  createdAt: string | null
  images: Array<{ url: string; mime: string }>   // روابط موقّعة، تنتهي بعد 15 دقيقة
  deductedHalalas: number | null          // ← اقرأ الشرح تحت
}
```

`404` لو الشكوى مش على وحدة بتاعة الشريك ده:
```json
{ "error": { "code": "NOT_FOUND", "message": "الشكوى غير موجودة" } }
```

## 2. إجابات أسئلتكم الخمسة

### أ. الشريك بيشوف إيه؟

الوصف، المرفقات، الحالة، كود الحجز، اسم الوحدة، وتاريخ التقديم. **وبس.**

### ب. مبلغ الخصم — `deductedHalalas`

**أيوة، هو `amount_partner` بتاع الاسترداد** — مش المبلغ اللي الضيف استلمه.

```
استرداد 500.00 على حجز مجمّد على 10%:
  الضيف بياخد        500.00
  deductedHalalas =   39130   (391.30 ريال)
```

الفرق مش تفصيلة: الضريبة بترجع لهيئة الزكاة والعمولة بترجع لممسى، **والشريك مابيتحملهمش**. عرض المبلغ الكامل هيخلي الشريك يشوف رقم أكبر من اللي في كشف حسابه ويفتح تذكرة دعم.

**`null` لحد ما الاسترداد يتسوّى فعلاً.** الحقل بيتملّي من صف `refunds` حالته `succeeded` بس — الصف الـ `pending` فلوس البوابة قبلتها ولسه ما تحركتش من رصيد الشريك. عرضها كخصم هيخلي الشريك يدوّر على قيد مش موجود في كشفه.

### ج. `internalNote` وجوال الضيف

**الاتنين مش في الرد إطلاقاً.**

- `internalNote` في `$hidden` على الموديل — مخفي على مستوى الموديل مش على مستوى كل resource، فحتى تسلسل مباشر للكيان مش هيسرّبه
- جوال الضيف مش في العقد أصلاً — الشريك مالوش خط مباشر مع المشتكي، التواصل بيمر عبر الأدمن

الاتنين متغطيين باختبار (`T13`) بيتأكد إن النص مش موجود في رد الشريك ولا رد الضيف.

### د. قيد الليدجر — الوصف والربط

```
type          refund_reversal
amount        سالب، = -deductedHalalas/100
ref_type      'refund'
ref_id        refunds.id  (نص)
ref_code      كود الحجز   ← ده اللي بيتعرض في كشف الحساب
description   "خصم بسبب شكوى على الحجز {code}"
```

**للربط من كشف الحساب للشكوى:** الطريق هو `ref_code` (كود الحجز) → الشكوى بتاعة الحجز ده. `ref_id` بيشاور على **الاسترداد** مش على الشكوى، فما ينفعش يتحط في رابط `/complaints/{id}` مباشرة.

لو محتاجين ربط مباشر بمعرّف الشكوى، قولوا وهنضيف `complaintId` للقيد أو لمخرج كشف الحساب — تعديل صغير، بس محتاج يتقرر قبل ما الشاشة تتبني عليه.

### هـ. `guestMessage`

**مش في رد الشريك.** ده النص اللي الأدمن بيكتبه **للضيف** مع القرار — لغته وسياقه موجّهين للضيف، وعرضه للشريك بيخلط الجمهورين.

## 3. الحالات اللي تهم الشاشة

| الحالة | معناها للشريك |
|---|---|
| `submitted` · `under_review` | شكوى مفتوحة، مفيش أثر مالي بعد |
| `approved` | ممسى اعتمدت مبلغ، **لسه ما اتخصمش** — `deductedHalalas` بيفضل `null` |
| `resolved_refunded` | اتخصم فعلاً — `deductedHalalas` فيه رقم |
| `resolved_rejected` | الشكوى مارفضتش لصالح الضيف — مفيش خصم |

⚠️ **`approved` مش معناها اتخصم.** فيه فترة بين اعتماد المبلغ وتسويته عند البوابة. الشاشة لازم تفرق بينهم، وإلا الشريك هيدوّر على خصم لسه ما حصلش.

---

## 4. المرفقات

روابط موقّعة **بتنتهي بعد ١٥ دقيقة**. ما تتخزنش في state طويل العمر ولا تتعاد بعد فتح الصفحة بمدة — أعيدوا جلب التفاصيل.

الصور دي صور بيت الضيف اللي أقام فيه، مرفوعة في نزاع؛ الرابط الدائم كان هيبقى قابل للتخمين وباقي للأبد.

---

## 5. ملاحظات

- كل الرسائل من الباك اند **عربية جاهزة للعرض** — ما تترجموهاش
- التواريخ ISO-8601 Zulu → اعرضوها `DD/MM/YYYY` بتوقيت الرياض
- العملة **ريال سعودي فقط**
- **ممنوع حساب أي تقسيم في الواجهة.** نسبة العمولة مجمّدة على كل حجز وممكن تختلف عن النسبة الحالية — `deductedHalalas` جاي من الـ API لسبب
