# رد الباك اند — نافذة التزامن على نفس المفتاح

**التاريخ:** 06/09/2026
**المرجع:** `MAMSA-REPLY-TO-BACKEND-idempotency-race.md`
**الحالة:** ✅ **اتصلح** — والنافذة كانت أخطر شوية من التوصيف · **524 اختبار، صفر فشل** · منشور على staging

قلتوا «يتعمل في أول لمسة جاية على الملف ده، مش في commit مخصوص». **اللمسة دي كانت دلوقتي** — كنا في نفس الملف بنشيل استثناء التسوية، فاتعمل.

---

## ١. التحليل صح، والإصلاح اتعمل

فحص المفتاح كان بره القفل فعلاً:

```
:76   فحص المفتاح       ← بره القفل
:80   DB::transaction   ← القفل بيبدأ
:125  الحارس            ← جوه القفل
```

دلوقتي فيه فحص تاني **جوه القفل، بعد قفل صف الحجز مباشرة**:

```php
$booking = Booking::…->lockForUpdate()->firstOrFail();

// متسلسلين ورا القفل دلوقتي: لو طلب توأم سبقنا، صفه موجود
if ($prior = Refund::where('idempotency_key', $idempotencyKey)->first()) {
    $replayed = true;
    return $prior;
}
```

الفحص البراني فضل مكانه — عشان إعادة الإرسال العادية (اللي بعد timeout) تفضل رخيصة ومتعملهاش قفل. والتعليق القديم اللي كان بيقول إنه «بيتعاد فحصه جوه ضد القيد الفريد» **اتصحح**: ما كانش فيه إعادة فحص أصلاً، وده كان بيدي انطباع غلط بالأمان.

---

## ٢. ⚠️ الإصلاح الساذج كان هيحوّل عيب شكلي لعيب حقيقي

نقطة تستاهل التنويه، لأنها مكانتش في تحليلكم وكانت هتفوت:

`execute()` بترجّع، وبعدين اللي بره بينادي `send($refund)` — وده اللي بينادي البوابة.

**فلو الفحص الجوّاني رجّع الصف الموجود على طول من جوه الـ closure، الصف ده كان هيتسلّم لـ `send()`** → **نداء تاني للبوابة لاسترداد موجود أصلاً**. يعني إصلاح النافذة الدلالية كان هيولّد المشكلة المالية اللي النافذة دي مكانتش بتسببها.

عشان كده فيه `$replayed`:

```php
if ($replayed) { return $refund; }   // مش بيروح لـ send()
return $this->send($refund);
```

**والحارس على ده موجود من قبل:** `once()` على mock ميسر في اختبار الترتيب — اللي أنتم نوّهتوا إنه «أهم من السؤال نفسه». لو حد شال `$replayed` بعدين، الاختبار ده هو اللي هيمسكه.

---

## ٣. اللي اتحقق منه واللي لأ — بصراحة

**اللي مقدرناش نختبره:** نافذة التزامن نفسها. اتصالين متوازيين مش ممكنين جوه نفس العملية — نفس القيد اللي موثّق في T20 وفي اختبار الحجز المزدوج.

**اللي اتحقق:** إن الفحص الجوّاني **كافي لوحده**. عطّلنا الفحص البراني وشغّلنا اختبار الترتيب:

```
الفحص البراني معطّل  →  ✓ الاختبار بيعدّي
                         (رجّع نفس refundId · replayed · ومفيش نداء تاني للبوابة)
```

يعني الفحص الجوّاني مش زينة — هو بيشتغل فعلاً، وبيرجّع النتيجة الصح، ومش بيكرر نداء البوابة.

## ٤. ملاحظتكم عن الاختبارات

> «الاختبارات بتتكتب حوالين اللي ممكن يبوظ، والدلالة الغلط مش بتبوّظ حاجة — بس بتخلي الأدمن يقفل الشاشة ويكلم الدعم»

ده أدق توصيف للفئة دي في السلسلة كلها. وبيفسّر ليه **الأربع أسئلة** كلها طلعوا منكم مش من الاختبارات: الاختبار بيسأل «هل النتيجة صح؟»، والأسئلة دي كانت بتسأل «هل اللي بيقرا النتيجة هيفهمها صح؟».

النوع ده محتاج حد يقرا آلة الحالة ويسأل. مفيش suite بيولّد السؤال ده من نفسه.
