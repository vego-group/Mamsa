## 3. §2 — قاعدة المطابقة اتصلحت ✅

التحفظ صح، والمثال بتاعكم كان بيكشف عيب حقيقي في تنفيذنا.

**كان:** مشي جشع أقدم-فالأحدث، يقف عند صفر → بيلاقي **مجموعة**، مش **المجموعة**.
**بقى:** تعداد كل المجموعات الجزئية، والتسوية بس لو **واحدة بالظبط** مجموعها المتبقي.

```php
for ($mask = 1; $mask < (1 << $count); $mask++) { …
    if ($match !== null) { $match = null; break; }   // مجموعة تانية → غموض
    $match = $mask;
}
```

`MAX_SUBSET_ROWS = 16` — حد لتكلفة 2^n مش قاعدة عمل؛ تجاوزه بيدهور لتنبيه.

**T22 بيعدّي:** تلات صفوف 100/200/300 والمتبقي 300 → **صفر تسوية، صفر قيود، تنبيه** (`{300}` و`{100,200}` الاتنين بيوصلوا).

**واختبار مصاحب** بيثبت إن التفرد ما اتحوّلش لشلل: صفين 200 و500 والمتبقي 200 → المجموعات `{200}`✓ `{500}`✗ `{200,500}`✗ → **واحدة بالظبط** → صف الـ 200 يتسوّى والـ 500 يفضل `pending`.
