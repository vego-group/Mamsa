**لمين:** فريق Next.js — لوحة الأدمن

## ٤. `GET /admin/permit-renewals` — **السقف 100، وإنتو بتطلبوا 100، فمافيش نقص**

- **السقف 100 على كل قوايم سطح الأدمن** (نفس الدالة).
- **أكبر من 100 مابيرجّعش خطأ:** بيتقص لـ100 بصمت، **بس الرد بيقول `pageSize: 100`**.
- **فاقروا `pageSize` و`total` من الرد، مش من الطلب.** لو `page × pageSize < total`، فيه صفحات تانية.

**الاختبار:** `PermitRenewalTest::test_the_page_size_is_capped_at_100_and_the_response_says_so` (`pageSize=500` ← الرد `100`).
لما رفعنا السقف لـ1000، الاختبار وقع.

**وفي العقد:** §١.٤ كان مكتوب فيه «≤100» من الأول، و§١.٥ (التجديدات) ماكانش. **اتكتب في §١.٥**، ومعاه إن الرد بيقول القيمة اللي اتطبّقت.

## ٥. ترتيب الفحص على `POST /admin/units/{id}/apartments` — **استنتاجكم صح في اتنين وغلط في واحد**

| الحالة | الخطوة | **قبل العَلَم ولا بعده؟** | استنتاجكم |
|---|---|---|---|
| **تضارب اسم الباب** (موجود في المبنى · مكرر في الطلب · `"1"`) | **مع الحقول** | **قبل** ← `422 VALIDATION_ERROR` · `fields["permits.{i}.apartmentNo"]` | ❌ قلتوا بعد |
| **التاريخ المنتهي** | جوّه الـtransaction | **بعد** ← `APARTMENT_INCOMPLETE` (§٦) | ✅ |
| **الرقم المكرر** (جوّه الطلب، أو مستعمل في إعلان تاني) | بعد الأصل الناقص | **بعد** ← `422 DUPLICATE_PERMIT_NUMBER` | ✅ |

**يعني على الإنتاج (العَلَم مقفول):**
- كارت **اسمه `"1"`** بيرجّع **`VALIDATION_ERROR`** على الكارت.
- كارت **تاريخه فات** أو **رقمه مكرر** بيرجّع **`MULTI_UNIT_DISABLED`**.

**والجدول اللي بعتناه يوم 02/10 (٥ خطوات) كان مختصر.** الترتيب الكامل **١٢ خطوة**، واتكتب في **دليل البناء §٨.٦**:

| # | الفحص | الرد |
|---|---|---|
| ١ | الوحدة مش موجودة | `404 NOT_FOUND` |
| ٢ | مش لممسى | `403 NOT_MAMSA_OWNED` |
| ٣ | مش `approved` | `409 SOURCE_NOT_APPROVED` |
| ٤ | شكل الحقول (`count` · `number` و`fileId` إلزاميين · صيغة التاريخ) | `422 VALIDATION_ERROR` |
| ٥ | الكروت مع وضع الترخيص | `422 PERMIT_MODE_MIXED` |
| ٦ | ملف كل كارت | `422 VALIDATION_ERROR` · `fields["permits.{i}.fileId"]` |
| ٧ | **اسم الباب** | `422 VALIDATION_ERROR` · `fields["permits.{i}.apartmentNo"]` |
| ٨ | **العَلَم والترخيص** | `MULTI_UNIT_DISABLED` · `MULTI_UNIT_REQUIRES_FACILITY_LICENSE` · `QUANTITY_EXCEEDS_LICENSED_UNITS` |
| ٩ | الأصل ناقص | `422 SOURCE_UNIT_INCOMPLETE` |
| ١٠ | عدد الكروت ≠ الأبواب · رقم مكرر جوّه الطلب | `PERMITS_COUNT_MISMATCH` · `DUPLICATE_PERMIT_NUMBER` |
| ١١ | جوّه الـtransaction: رقم مستعمل في إعلان تاني | `DUPLICATE_PERMIT_NUMBER` |
| ١٢ | جوّه الـtransaction: كل باب جديد على بوابة الإرسال | **`APARTMENT_INCOMPLETE`** |

**الاختبارات:**
- `ApartmentsTest::test_a_door_name_conflict_is_refused_before_the_rollout_flag`: العَلَم مقفول وكارت اسمه `"1"` ← `VALIDATION_ERROR`.
  **لما نقلنا فحص الاسم بعد العَلَم، الاختبار وقع.**
- `ApartmentsTest::test_an_expired_or_repeated_card_is_judged_after_the_rollout_flag`: العَلَم مقفول ← تاريخ منتهي ورقم مكرر
  الاتنين `MULTI_UNIT_DISABLED`، ولما العَلَم يتفتح الرقم المكرر ← `DUPLICATE_PERMIT_NUMBER`.

## ٦. `APARTMENT_INCOMPLETE` — إمتى وشكله

**على سطح الأدمن بس.** باب جديد اتعمل جوّه الـtransaction ومعدّاش **بوابة الإرسال** (نفس فحص `submit`)، فالمبنى كله بيترجع.

```json
// 422
{
  "message": "تعذّر إنشاء الوحدات — إحدى النسخ غير مكتملة",
  "code": "APARTMENT_INCOMPLETE",
  "fields": { "permitExpiresAt": "تصريح الوحدة منتهي — جدّده قبل الإرسال للمراجعة" },
  "meta": { "apartmentNo": "3" }
}
```

- **إمتى عملياً: كارت تاريخه فات.** (أو كارت من غير تاريخ، لو `permitExpiryRequired` اتقلب `true`.) أي نقص تاني في الكارت
  بيقع قبل كده في الخطوة ٤، ونقص الأصل في الخطوة ٩. فالـmock يكفيه السيناريو ده.
- **`fields`** بمفاتيح الويزارد، **من غير رقم الكارت.**
- **`meta.apartmentNo`** = اسم الباب اللي وقع. طابقوه على الكارت اللي `apartmentNo` بتاعه نفس القيمة. ولو الكارت ماكانش مسمّي،
  ده الرقم التلقائي اللي كان هياخده، **فالأسهل تعلّموا كل كارت `expiresAt` بتاعه قبل النهارده بتوقيت الرياض** (نفس شرط السيرفر،
  الملحق §١.٢).
- **مافيش أي حاجة اتكتبت:** ولا باب، ولا تصريح، والأصل زي ما هو.
- **على لوحة الشريك نفس الحالة** بترجع `400 VALIDATION` + `fields.permitExpiresAt` **من غير `meta`** (الملحق §١.٢). يعني الأدمن
  عنده معلومة زيادة (`apartmentNo`).

**الاختبار:** `ApartmentsTest::test_an_expired_card_rolls_the_building_back_as_apartment_incomplete`. بيتأكد من الكود والرسالة
و`meta.apartmentNo` ومفتاح `fields.permitExpiresAt`، **وإن عدد الوحدات والتصاريح ماتغيّرش.** **لما قفلنا بوابة الإرسال، الاختبار وقع.**
**وماكانش فيه أي اختبار على `APARTMENT_INCOMPLETE` قبل النهارده.**
